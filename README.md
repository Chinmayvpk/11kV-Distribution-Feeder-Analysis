# 11-kV Distribution Feeder Analysis & Design Tool

A MATLAB App Designer application for analyzing and evaluating an 11-kV distribution feeder.

## Features

* Feeder input parameter calculation
* Four-section load analysis
* Feeder current calculation
* Voltage drop and voltage profile analysis
* Voltage regulation calculation
* Power loss calculation
* Automatic conductor selection
* Conductor ampacity evaluation
* Conductor comparison table
* Performance summary report
* Report generation and download functionality
* Graphical voltage profile and power-loss visualization

## Technologies Used

* MATLAB
* MATLAB App Designer
* MATLAB UI components
* Electrical power-system calculations

## Project Structure

* `Application.mlapp` — Main MATLAB App Designer application

## How to Run

1. Download or clone this repository.
2. Open `Application.mlapp` in MATLAB.
3. Run the application using MATLAB App Designer.
4. Enter the feeder and conductor parameters.
5. Click **ANALYZE FEEDER**.
6. View the analysis results, conductor evaluation, and generated report.

## Project Purpose

This project demonstrates the application of electrical engineering concepts and MATLAB-based GUI development for distribution feeder analysis and conductor selection.
